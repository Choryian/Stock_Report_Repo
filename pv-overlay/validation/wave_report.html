파동 위치 조건부 검증 (T5) — 1파 · 3파 · 5파

유니버스 716종목 · 점-시점(point-in-time) 라벨 136개 표본일(4주 간격 수요일, 2016~2026) · 각 표본일까지의 데이터만으로 elliott-wave-dashboard 엔진(auto_label) 실행 → look-ahead 없음 · Intermediate = 주봉 2년창, Minute = 일봉 6개월창, 각 계위 독립 판정(대시보드의 top-down 포함관계는 미적용) · conf ≥ 0.3 · 60일 시장조정 로그 초과수익 · [ ] = 종목 클러스터 부트스트랩 95% CI · 굵게 = CI가 0 배제

판정 요약

① "3파의 거래량 폭발은 건전, 5파의 거래량 폭발만 클라이맥스" — 기각. 거래량 과다 경고(효율비 최하위 10%)의 60일 효과는 Intermediate 기준 1파 −3.16%p, 3파 −3.16%p, 5파 −3.93%p로 세 파동 모두 유의하게 음수이고, 5파−3파 차이는 −0.77%p [−3.88, +2.80]로 구분되지 않는다. Minute도 3파 −2.27, 5파 −2.99로 동일. 거래량선이 가격선을 크게 앞지르면 파동 위치와 무관하게 되돌린다.
② Minute 5파 라벨 자체가 역발상 신호, 경고와 중첩하면 가장 강함. Minute "5 up" 무조건 60일 −1.31% [−2.14, −0.51] (점-시점 라벨 중 유일하게 CI가 0을 배제하는 상승 임펄스). 여기에 효율비 최하위 10%를 겹치면 −3.78% (n=826), Q1·거래량선 상승폭 상위⅓이면 −3.69%. 반대로 Minute "5 down"(하락 5파)은 +1.13% [+0.63, +1.61] — 하락 클라이맥스 반등.
③ 5파에서는 거래량 크기가 갈림길. Intermediate 5파 Q1(가격↑거래량↑) 내부: 거래량선 상승폭 소 +1.83% / 중 −1.11% / 대 −1.84%, 대−소 = −3.68%p [−7.17, −0.44]. 조용히 오르는 5파는 연장되고, 거래량이 붙는 5파는 끝난다. 3파에서는 같은 스프레드가 −1.26%p [−3.57, +1.14]로 유의하지 않음 — 3파는 거래량 크기로 갈리지 않는다.
④ 1파(Intermediate)의 거래량 과열은 "가짜 출발" 경고. 1파 효율비 하위⅓ −2.33% vs 중간⅓ +0.99%, 최하위 10% −3.26% [−5.51, −0.89]. 새 임펄스 초입에 거래량이 가격을 크게 앞지르면 1파가 아니라 B파일 가능성 — 카운트 재검토 트리거로 쓸 수 있다. 단 Minute 1파에서는 재현되지 않음(−0.66, CI 0 포함).
⑤ 엔진 라벨의 무조건 정보량은 낮다. Intermediate 1·3·5 up 전부 CI가 0을 포함. 즉 "지금 3파"라는 자동 라벨만으로는 수익 예측이 안 되고, 거래량 오버레이가 라벨 위에 얹혀야 정보가 생긴다. 이 조합이 이번 검증의 핵심 산출물이다.

실전 룰 (파동 조건부)

  • 모든 상승 임펄스 공통: 효율비 횡단면 최하위 10% 진입 = 60일 −3%p 경고. 3파라고 면제 없음.
  • Minute 5파 + 경고 = 가장 강한 매도/신규진입 금지 조합 (−3.8%). 5파 라벨 단독도 −1.3%.
  • 5파 홀딩 판단: Q1인데 거래량선 10일 상승폭이 하위⅓이면 홀드(+1.8%), 상위⅓이면 익절(−1.8~−3.7%).
  • Intermediate 1파 판정 검증: 거래량 과열 동반 시 1파 카운트 신뢰도 하향(B파 대안 카운트 병기).
