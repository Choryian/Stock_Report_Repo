고정 앵커 효율비 + top-down 라벨 재검증 (T6)

유니버스 716종목 · 점-시점 top-down 라벨 136표본일 (Cycle→Intermediate→Minute 포함관계, 대시보드 정본과 동일 체인, 조정 전파 포함) · 앵커 = 엔진 phase_start(현재 파동 시작일) · conf ≥ 0.3 · 60일 시장조정 초과수익 · [ ] 종목 클러스터 부트스트랩 95% CI · 굵게 = CI 0 배제

판정 요약

① 고정 앵커 버전은 롤링 60일 버전을 이기지 못한다. Intermediate 경고 효과: 1파 앵커 -3.25% vs 롤링 -3.56%, 3파 앵커 -2.44% vs 롤링 -3.14% — 둘 다 유의하지만 롤링이 같거나 더 크다. Minute은 앵커 경과가 중앙값 16~35일로 짧아 앵커 지수가 불안정, 경고 효과 대부분 CI가 0 포함. 운영 정의는 롤링 60일로 유지, 앵커는 차트 표시 장치로만.
② 앵커가 주는 한 가지 실용 룰 — 3파에서 "거래량선이 가격선 위"면 나쁘다. Intermediate 3파: 거래량선 위 -0.52% vs 아래 +1.18%, 차이 -1.70% [-3.11%, -0.31%]. 이진 판정이라 차트에서 눈으로 바로 읽힌다(대시보드 이식본의 보라선이 가격선 위에 있는가). 1파는 같은 부호지만 CI 0 포함, 5파는 무차이.
③ top-down 라벨로도 T5 핵심이 재현된다. 경고 효과 1파·3파 유의 음수(5파는 표본 축소로 CI 확대, 부호 동일). Minute "5 up" 무조건 -1.30% 유의 음수 재현, "5 down"·"3 down" 양수 재현. 3파 면제 없음도 동일.
④ top-down의 비용: 미정(?) 급증. Intermediate 미정 27,859행(독립 판정 18,838), Minute 35,033행(독립 18,355). 부모 조정 전파로 자식이 ABC/미정으로 강등되어 상승 임펄스 표본이 30~40% 줄었다. 대시보드 정본이 "정직한 미정"을 택한 대가이며, 통계 검증용으로는 독립 판정 라벨이 더 효율적.

최종 운영 룰 (T1~T6 종합)

  • 경고 정의: 롤링 60일 효율비 횡단면 최하위 10% (또는 Q1·거래량선 10일 상승폭 상위⅓). 파동 위치 무관, 60일 −2~−3.5%p.
  • Minute 5파(up) + 경고 = 신규진입 금지·익절. 5파 라벨 단독도 −1.3%.
  • 3파 차트 룰: 파동 시작 앵커 이후 보라 거래량선이 가격선 위 → −1.7%p. 아래면 정상 3파(+1.2%).
  • 5파 홀딩: Q1인데 거래량선 상승폭 하위⅓ 홀드 / 상위⅓ 익절.
  • 앵커 효율비는 표시용. 판정은 롤링 60일 값으로.
